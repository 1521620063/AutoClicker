# 安卓固定位置连点器：第一版设计

日期：2026-10-08
状态：用户已确认；源码已实现，正在推进构建与验收，完整 APK 构建等待 SDK 许可确认。

## 目标与范围
用户需要能安装到安卓手机上的固定位置持续点击工具。成功标准是在用户主动启用无障碍服务后，可定位目标、设置间隔、开始持续点击并可靠停止。
第一版仅单点点击，不支持多点、滑动、脚本、识图、自动启动、联网、广告、账号或 Root。界面为中文。构建目标为可安装的 debug APK，不承诺商店发布。

## 技术方案
采用 Kotlin 原生安卓应用，最低 Android 7.0 / API 24。通过 AccessibilityService.dispatchGesture 执行点击，并在服务配置中声明 canPerformGestures。用户必须自行在系统设置中开启服务，应用不能绕过该授权。
悬浮控制器采用 TYPE_ACCESSIBILITY_OVERLAY，由无障碍服务管理，不额外申请普通应用悬浮窗权限。只使用完成操作所需的能力，不读取界面节点、文本或截图，不申请 INTERNET 权限。
相比 Root 注入或 ADB 连接，此方案适合普通手机本地使用。具体 compileSdk、targetSdk、Gradle 与插件版本在实施阶段依据官方文档及可用环境确定。

## 页面与交互
主页面包含服务状态、用途与权限说明、开启服务按钮、点击间隔输入框、显示控制器按钮及简要使用说明。
点击间隔默认 100 毫秒；接受 50–60000 毫秒整数。无效输入给出中文提示，不启动点击。保存合法间隔，重启后恢复；不自动恢复执行状态或点击坐标。
控制器提供开始/停止及关闭按钮。另有可拖动靶心，定位后以屏幕像素坐标为点击目标，边界限制在当前可用屏幕内。控制条可拖动，不能完全移出屏幕。
未定位时不允许开始，提示用户拖动靶心。开始时隐藏靶心窗口，保证目标处不会被其拦截；停止后恢复靶心。执行期间禁止调整坐标与间隔。控制条覆盖目标时不允许启动，提示移动控制条。关闭控制器同时停止并移除全部悬浮窗口。

## 组件与数据流
- MainActivity：中文设置、授权引导、状态显示、输入校验。
- SettingsRepository：通过本地偏好保存间隔，不保存敏感信息。
- AutoClickAccessibilityService：服务生命周期、控制器命令和系统事件。
- OverlayController：创建、拖动、隐藏、恢复及移除悬浮窗口。
- ClickScheduler：启动/停止、间隔调度、单次手势回调和运行代次管理。
主页面请求显示控制器时先确认服务已连接。所有调度和窗口变更串行运行在主线程。只有手势完成或取消后才允许下一次分发，禁止重叠手势。开始时间之间的目标间隔为用户设置值；手势或系统延迟导致间隔变长时不补发积压点击，不保证精确实时频率。单次手势持续时间设为短点击（计划 20 毫秒）。
停止使运行代次失效并移除待执行任务；迟到回调不能重新启动循环。系统已接收的当前手势可能完成，但停止后不得派发新的手势。

## 安全与异常
锁屏、屏幕关闭、配置变化（包括旋转）、服务解绑或销毁、手势分发拒绝或取消时停止点击。旋转后移除控制器，要求用户重新定位。再次连接服务不自动启动或显示控制器。
开始前检查设备处于解锁且亮屏状态。停止和关闭操作幂等。窗口创建失败时回收已创建窗口并显示错误。不使用后台无限重试。
运行时控制条保持可用；应用不会主动点击授权确认、输入凭据或隐藏自身运行状态。系统或厂商限制可能影响实际点击效果，需要设备验证。

## 测试与验收
自动化测试覆盖间隔边界及无效输入、重复启动、停止后的回调、分发失败/取消、无重叠调度及禁止积压补发。
构建验收：运行单元测试与 debug APK 构建，记录实际结果。未成功构建不可声称已交付 APK。
真机或模拟器验收：授权流程；拖动定位；以 100 毫秒间隔点击测试按钮；停止后计数不再增长（已分发手势除外）；关闭后窗口消失；锁屏停止；旋转停止且要求重新定位；服务关闭后不再点击；靶心隐藏后点击可以落到下层应用。
没有设备时明确标注真机验收未完成，不以单元测试代替权限、窗口和跨应用点击验证。

## 1.1.0 增量设计（对话确认，2026-10-08）

用户随后批准的增量需求替代第一版的对应限制：间隔下限改为 10 毫秒；按下时长默认 5 毫秒，可设 1–100 且不超过间隔；启动倒计时立即/1/3/5 秒；自动停止选择持续、完成指定手势次数或指定运行时长，次数 1–1000000，时长 1–86400 秒且不含倒计时。配置保存，停止后才允许修改；不保存坐标或自动运行。

实时频率单独开关，默认关闭且保存；统计当前运行最近一秒成功完成手势，窗口 `(now-1000, now]`，每 500 毫秒刷新，不代表目标应用响应，也不是理论频率。倒计时等待开始；停止清零，重启不继承旧手势。悬浮统计区域固定高度。其余停止、权限与隐私要求保持不变。验证结果见 docs/verification.md 的 1.1.0 章节。
