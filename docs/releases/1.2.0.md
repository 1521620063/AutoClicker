# 轻点 v1.2.0

## 更新内容

- 点击间隔最低 10 毫秒，增加快捷间隔、按压时长、启动倒计时及次数/时长自动停止。
- 可开启实时点击频率：统计最近一秒系统成功完成的手势，每 500 毫秒刷新；不代表目标应用成功响应次数。
- 雾白与翡翠绿界面升级，独立配置分组、突出主要操作、统一控件状态及悬浮控制面板。
- APK 自动带版本号和 debug 标识；补充可跨机器使用的 AGENTS.md。
